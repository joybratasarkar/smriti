# Contributing to Smriti

Thanks for your interest. Issues and pull requests are welcome.

## How to contribute

1. Open an issue first for anything bigger than a small fix, so we can agree on the approach.
2. Keep changes small and readable. No new frameworks without a reason.
3. Follow the accuracy rules: every event must be traceable to a source article, and only links and metadata are stored, never full article text.
4. In your pull request description, include this line:

   > I have read and agree to the Contributor License Agreement in CONTRIBUTING.md.

Pull requests without that line can't be merged.
